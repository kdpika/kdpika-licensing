# KDPika Licensing Python SDK

A typed API-v1 client for activating one persistent software installation,
checking signed access and releasing its seat. **1.1.0rc1 is unpublished.**

Start with [Getting started](getting-started.md), then [Concepts](concepts.md)
and the generated [API reference](api.md). Check [Security](security.md) and
[Migration](migration.md) before shipping to customers.

This documentation describes the Python candidate, not a new server API.
Use the [platform documentation](https://licensing.kdpika.com/docs) for product
setup and the current API-v1 contract. Hosted docs/downloads can still describe
the previous approved SDK release until the coordinated owner release.
